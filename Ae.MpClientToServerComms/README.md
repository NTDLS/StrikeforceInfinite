# Axis Engine
Axis Engine is a 2D game engine written in C# (currently .net10) and rendered with DirectX.
The engine features infinite space, neural network AI, multiple scenarios, single-player, multi-player, locking/seeking weapons, a "speed-scaled" environment, dozens of weapons and massive fiery explosions...

Check out the alpha build 13 gameplay on YouTube: [https://www.youtube.com/watch?v=Kd-aEshWiNg](https://youtu.be/uxRjQ9BHlek)

# Ae.MpClientToServerComms
The Ae.MpClientToServerComms project is intended to handle communication between the client and server in a multi-player environment.

**Please note that multi-player is only partially implemented and is not yet available for public use**
